Embedded adaptations and credits:
- GlassFolder: glass layers, file fan, spring curves and procedural artwork math.
  https://leibox.pantoria.cn/docs/animations/glass-folder
- TactilePushButton: surface, seven inset shadows, press/hover behavior.
  Community submission by 少荃 (Douyin: 宝龙体育优品小铺).
  https://leibox.pantoria.cn/docs/animations/tactile-push-button
- GlassTabMenu: substepped spring integration and morphing glass navigation,
  rebuilt for a responsive chapter picker. Reference author: solutionb.
  https://x.com/SolutionB2u
  https://leibox.pantoria.cn/docs/animations/glass-tab-menu
- CosmicPanels: rotating projected orbital geometry, adapted for the toolbox.
  Reference author: Acream https://x.com/acream_1
  https://leibox.pantoria.cn/docs/animations/cosmic-panels
- FluidTooltip: interaction reference for the custom sliding navigation capsule;
  implemented independently with CSS and React; bundled GSAP not included.
  https://leibox.pantoria.cn/docs/animations/fluid-tooltip
