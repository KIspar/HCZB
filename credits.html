交互与视觉

改编自 LeiBox：按压按钮 TactilePushButton，以及参考 GlassTabMenu 交互整理的六步指南导航。以原生 JavaScript 与 CSS 适配本页。保留 LeiBox 许可说明。

首屏编排台与工作流为 HTML / CSS 功能示意，使用虚构企业与岗位数据；背景由 Canvas 绘制。连续滚动转场使用 CSS 蒙版、布局变换与原生滚动时钟，操作指南使用扩展的界面截图。

立体按钮投稿：少荃；玻璃菜单参考作者：solutionb。本版下载入口使用独立文件链接。顶部滑动导航沿用 FluidTooltip 的交互参考。

章节衔接研究参考 Codrops SeamTransitions 与 ScrollBasedLayoutAnimations 的视觉思路。本页没有复制其源码、图片或接入滚动平滑插件。
