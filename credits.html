素材与组件

本页使用 HCZB 品牌与现有教程内容，整合 LeiBox 交互组件。

图标

35 个 SVG 来自 iconfont · Remix 合集，上传者 JAYJAY。上传者不等同于 Remix 原作者；图标作为界面的一部分使用，原始设计与许可归对应权利人所有。

交互与视觉

改编自 LeiBox：立体按压按钮 TactilePushButton、玻璃标签菜单 GlassTabMenu、玻璃文件夹 GlassFolder。以原生 JavaScript 与 CSS 适配本页。保留 LeiBox 许可说明。

首屏立体播放台、任务浮层及背景由 CSS 绘制，图标来自上述合集。已收集的 Blender 素材未在此版本中渲染使用。

立体按钮投稿：少荃；玻璃菜单参考作者：solutionb。文件夹使用原组件的分层、扇形展开与程序化纹理算法。顶部滑动导航沿用 FluidTooltip 的交互参考。

教程与文件

视频、操作截图、扩展安装包与离线指南复制自现有 HCZB 项目。此页不会访问招聘资料、任务 JSON 或 API Key。

字体
